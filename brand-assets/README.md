# UBC Brand Assets

Official UBC 2018 brand assets for use in ECO-COMS and related Workday Extend apps.

## Logo variants

| Variant | Description |
|---------|-------------|
| `fullsig` | Full signature — crest + wordmark stacked vertically |
| `narrowsig` | Narrow signature — crest + wordmark side-by-side |
| `wordmark` | Wordmark only (text: "The University of British Columbia") |
| `crest` | Crest/shield only |
| `letterforms` | "UBC" letterforms only |

## Colours

Each variant comes in three colours: `blue` (UBC Blue #002145), `black`, `white`.

## Resolutions

- `png-web-72dpi/` — Screen/web use (72 dpi, RGB)
- `png-print-300dpi/` — Print/high-res (300 dpi, RGB)

## Usage in Workday Extend apps

The `presentation/assets/ubc-wordmark.png` in this repo is the blue wordmark
at 72 dpi, used in the ECO-COMS hub landing page header.
